🏝️ Jogo de Sobrevivência na Ilha Deserta

Um jogo em modo texto interativo desenvolvido em Python para consolidar os conceitos fundamentais de estruturas de controle, condicionais, laços de repetição e operadores lógicos.

📌 Sobre o Projeto

Neste jogo, o jogador se encontra preso em uma ilha deserta e precisa tomar decisões estratégicas ao longo de 3 dias para sobreviver. Cada escolha afeta suas vidas e seu inventário de recursos disponíveis, alterando o resultado e o final do jogo.

Projeto desenvolvido com foco em praticar a sintaxe do Python e boas práticas de lógica de programação.

🛠️ Tecnologias e Conceitos Utilizados

O projeto utiliza exclusivamente bibliotecas nativas do Python e aplica os seguintes conceitos da linguagem:

Estruturas Condicionais: if, elif, else

Laços de Repetição: while (controle dos dias e estado do jogo) e for (iteração do inventário)

Operadores Lógicos: and, or e not

Manipulação de Tipos e Variáveis: bool, int, str e listas (list)

🚀 Como Executar o Projeto

Pré-requisitos

Ter o Python 3.x instalado na sua máquina.

Ter o VS Code (ou outro editor de sua preferência).

Passo a Passo

Clone o repositório:

git clone https://github.com/SEU-USUARIO/ilha-sobrevivencia.git


Acesse a pasta do projeto:

cd ilha-sobrevivencia


Execute o jogo:

python main.py


🎮 Como Jogar

Ao iniciar o jogo, você terá 3 vidas e 3 dias para sobreviver na ilha.

A cada dia, escolha entre 3 opções digitando o número correspondente (1, 2 ou 3):

1: Explorar a mata fechada em busca de ferramentas.

2: Ir pescar na praia (a chance de sucesso depende dos itens coletados).

3: Descansar no acampamento.

Fique atento às combinações de recursos! Ter itens em seu inventário influencia diretamente a resolução dos seus dias.
